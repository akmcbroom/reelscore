## Gotchas discovered

- **D1 caps statements at 100 bound parameters** — the score upsert must be
  chunked (≤10 rows × 9 cols); handled in `src/lib/server/scores.ts`.
- shadcn-svelte CLI `--preset` wants an encoded code, not a name — `b0` is
  the default config (nova/neutral/lucide/inter). Derived via the package's
  own `encodePreset` from `shadcn-svelte/dist/preset`.
- `sv create` add-on `sveltekit-adapter=adapter:workers` crashes (CLI bug) —
  scaffold with tailwind only, add `@sveltejs/adapter-cloudflare` manually.
- Svelte component libs (@lucide/svelte) need vite `ssr.noExternal` — Node
  can't load raw `.svelte` files when externalized.
- `wrangler types` must emit into `src/` (`src/worker-configuration.d.ts`)
  or svelte-check can't see Env/D1Database/KVNamespace globals.
- `page.url` from `$app/state` is NOT reactive to shallow `pushState` — use
  `page.state` for modal reactivity (URL params only for direct loads).
- Newest SvelteKit template has **no svelte.config.js** — kit config lives in
  vite.config.ts `sveltekit({...})` plugin options; runes forced on.
- Grid-item blowout strikes in any framework: dialog children need `min-w-0`
  or the episode carousel's min-content width stretches the dialog.
- Local D1/KV state survived both migrations (same `.wrangler/state`) — the
  score cache stayed warm all day.
